iPhone 自動搶購控制台

待命 · 等待前端指令
  1. 1. 設定 Worker揀機型、門市、數量，每個 Worker 用唔同 session 資料夾（一個資料夾 = 一個 Apple ID）。
  2. 2. 儲存再啟動撳綠色「儲存設定」，再開測試模式「全域啟動」。系統先會開 Chromium。
  3. 3. 登入 Apple ID喺彈出嘅嗰個 Worker 視窗登入。登入一次就會記住。登入完已經開始查庫存。
  4. 4. 搶夠自動停達到購買上限就停搶，視窗會留住。換第二個 Apple ID 請新增 Worker 用新 session，唔使刪舊資料。
全域啟動進行中：畫面上嘅 Worker 設定已鎖定，改動唔會套用到正在跑嘅程式。要改設定請先緊急停止，儲存後再啟動。
