iPhone 自動搶購控制台

待命 · 等待前端指令
  1. 1. 設定 Worker揀機型、門市、數量，每個 Worker 用唔同 session 資料夾（一個資料夾 = 一個 Apple ID）。
  2. 2. 儲存設定撳綠色「儲存設定」。全域啟動只會用已儲存嘅 Worker。
  3. 3. 登入 Apple ID撳該 Worker 嘅「登入 Apple ID」，視窗會帶到最前並打開登入頁。登入成功後先會顯示電郵，狀態變成待命。
  4. 4. 開始搶機待命之後先可以「開始運作」或「全域啟動」。搶夠上限會自動停；停止運作唔會登出。
有 Worker 正在搶機：嗰粒嘅設定已鎖定。其他 Worker 仍可登入、開始或停止運作。緊急停止會關閉全部瀏覽器。

請先儲存、登入 Apple ID 變成待命，再按開始運作或全域啟動。後台唔會自行開跑。
